Crée une application web complète de gestion financière en React/Next.js avec Tailwind CSS, en utilisant strictement la palette jaune (#FFD700) et vert (#228B22) comme thème principal.

## 🎯 FONCTIONNALITÉS GLOBALES

### 1. AUTHENTIFICATION & SÉCURITÉ
- **Page d'authentification unique** avec onglets Connexion/Inscription
- **Inscription** : nom, email, téléphone, mot de passe (≥6 caractères)
- **Connexion** classique et via Google/Facebook (boutons distincts)
- **Mot de passe oublié** avec lien de réinitialisation
- **Validation** des champs avec messages d'erreur clairs
- **Logo "MF"** (MesFactures) présent sur toutes les pages

### 2. GESTION DES FACTURES (URL: /factures)
- **CRUD complet** : ajout, modification, suppression
- **Formulaire** : fournisseur, type (électricité, eau, internet), montant (en Ariary), dates (émission/échéance), statut (payée/en attente)
- **Historique avec filtrage** : par type, statut, période + pagination
- **Export** PDF/Excel des données filtrées
- **Scan OCR** (Tesseract.js) : capture photo/caméra + extraction texte automatique
- **Badges colorés** : vert (payée), jaune (en attente), rouge (en retard)

### 3. GESTION DES DÉPENSES (URL: /depenses)
- **CRUD dépenses fixes et variables** : description, catégorie, montant (Ar), type, fréquence (unique/mensuelle/annuelle/hebdomadaire), date
- **Alertes budget** : détection dépassement + notifications visuelles
- **Visualisation** : graphiques interactifs (comparaisons mensuelles/annuelles)
- **Catégorisation intelligente** : IA de suggestion automatique de catégories
- **Synchronisation** avec les factures payées

### 4. GESTION DES REVENUS (URL: /revenus)
- **CRUD sources de revenus** : nom, type (fixe/variable), montant (Ar), fréquence (mensuelle/annuelle/ponctuelle)
- **Plafond d'utilisation** : configuration en pourcentage (0-100%) avec barre de progression
- **Section plafond global** : définition et suivi du plafond mensuel général
- **Filtres avancés** : identiques au module factures

### 5. GESTION DES PRÊTS (URL: /prets)
- **CRUD prêts** : créancier, montant, taux, durée, date début
- **Calcul automatique** des échéances et montants totaux
- **Simulation** : scénarios (6/12 mois, taux variable) + visualisation graphique
- **Historique** avec tri/filtrage par statut
- **Calendrier de remboursement** avec notifications

### 6. OBJECTIFS & RECOMMANDATIONS (URL: /objectifs)
- **Gestion % épargne** : définition objectifs + répartition automatique
- **Simulation épargne** : progression graphique + planification automatique
- **Recommandations personnalisées** : analyse habitudes + suggestions économies
- **Tableaux et rapports** visuels

### 7. NOTIFICATIONS & AUTOMATISATIONS
- **Rappels et alertes** : factures/dépenses/prêts (pop-up/push)
- **Détection automatique** des échéances
- **Import/Export** : CSV, API bancaire, PDF, Excel
- **Traitement** : vérification doublons, mise à jour automatique

### 8. TABLEAU DE BORD (URL: /dashboard)
- **Analyses globales** : graphiques revenus/dépenses/objectifs/épargne/prêts
- **Prévisions et tendances** : projections + algorithmes prédictifs
- **Détection anomalies** : alertes dépenses inhabituelles
- **Filtres avancés** : période, catégorie, comparaisons

### 9. GAMIFICATION (URL: /defis)
- **Défis et récompenses** : défis personnalisés avec suivi progression
- **Système de badges** : bronze/argent/or/diamant selon performances
- **Intégration objectifs** : liaison défis-objectifs financiers

## 🎨 EXIGENCES TECHNIQUES & DESIGN

### Stack Technique
- **React/Next.js** avec App Router
- **Tailwind CSS** pour le styling
- **Composants shadcn/ui** pour l'interface
- **Heroicons** pour les icônes
- **Recharts/Chart.js** pour les graphiques
- **Tesseract.js** pour l'OCR

### Structure du Projet
```
/src
  /features
    /auth/ (LoginForm, RegisterForm, AuthPage)
    /factures/ (FactureForm, FactureTable, FactureFilters, FactureOCRUploader)
    /depenses/ (DepenseForm, DepenseTable, DepenseChart, BudgetAlert)
    /revenus/ (RevenuForm, RevenuTable, PlafondConfig)
    /prets/ (PretForm, PretTable, PretSimulation, PretCalendar)
    /objectifs/ (ObjectifForm, EpargneChart, RecommandationsAI)
    /notifications/ (NotificationPopup, ImportExportModule)
    /dashboard/ (DashboardPage, RevenueChart, ForecastChart)
    /gamification/ (ChallengeCard, BadgeGallery)
  /components
    /shared/ (Navbar, Sidebar, Button, Card, Modal)
```

### Consignes Stylistiques Strictes
- **Palette exclusive** : jaune (#FFD700) et vert (#228B22) (couleur principale)
- **Design moderne et responsive** (desktop + mobile)
- **Boutons arrondis** avec ombres légères
- **Badges colorés** pour les statuts
- **Réutilisation stricte** des composants et styles existants
- **Cohérence visuelle** totale entre toutes les pages

### Spécificités Métier
- **Devise** : tous les montants en Ariary (Ar)
- **Dates** : format jour/mois/année
- **Navigation** : URLs fixes (/auth, /factures, /depenses, /revenus, /prets, /objectifs, /dashboard, /defis)
